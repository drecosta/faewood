# Materials

Material names used by runtime palette swapping: `Skin`, `Hair`, `Dress`, `Shoe`, `Eye`, `WingGlow`, `Bark`, `Leaf`, `Crystal`, `Cap`, `Stem`, `CaveRock`, `CaveMouth`, `Vine`.

Prefer Principled BSDF in Blender and keep one material per colour group so `setPalette()` can update every matching mesh.
